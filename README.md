# Inventory Control Suite

Production-oriented inventory and project operations platform built with Next.js, Express, PostgreSQL, Prisma, and shadcn-style UI primitives.

## Stack

- Next.js App Router frontend
- Express API backend
- PostgreSQL with Prisma
- Tailwind CSS design system
- Middleware-based routing and API protection

## Start

1. Copy `.env` and fill in the database URL and secrets.
2. Run `npm install`.
3. Run `npm run prisma:generate`.
4. Run `npm run dev`.

## Structure

- `app/` Next.js routes
- `components/` reusable UI and layout components
- `hooks/` reusable data-fetching hooks
- `server/` Express API and Prisma integration
- `prisma/schema.prisma` database contract
